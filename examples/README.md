# Listening examples

These files come from Orcun Duzbeyaz's original Music Engine prototype:

| File | Original filename |
| --- | --- |
| `prototype-output-1.mp3` | `output 1.wav` |
| `prototype-song-1.mp3` | `song 1.wav` |
| `prototype-song-10.mp3` | `song 10.wav` |
| `prototype-song-0.mid` | `song (0).mid` |

The WAV recordings were converted to 128 kbps MP3 to keep this repository small. The MIDI is a separate prototype example; it is not claimed to correspond to any of the three recordings. Generation settings and seeds are unknown.
